# CNIT-381
Weekly labs for CNIT-381

## Week 1
Created the repository, configured Git, cloned it locally, and made my first commit.

## Week 2
Practiced team Git collboration with a partner: feature branches, pull requests, code review, and resolving a merge conflict on a shared network inventory site.

## Week 3
Containerized a duplicate-IP checker with Docker and published the image to Docker Hub.

## Week 4
Built a network config pipeline: an intent file plus a generator, containerized, with CI/CD that regenerates and validates the configs on every change.

## Week 5
Called the GitHub REST API from Python to read my repo and create an issue.

## Week 6
Created a Python checker for our IP Address plan, packaged in Docker, and ran it via GitHub Actions on a push or pull which open an issue when the API has errors.

**REPO:** https://github.com/Joseph-W0lf/IP-Plan-Check

**What I Learned:** There are so many different things that you can do in the networking and computer science world. They all have different ways that they can interact with each other to create this cohesive architecture that function like a well oiled machine. Building programs and packaging them in Docker for GitHub to run are some skills that I'll most likely be using in my future at some point. I'm excited to learn more and see how they interact with other programs that I've yet to learn.

**Challenges:** I mostly have difficulties with GitHub authentication because I try to run both my school and personal account on the same device and SSH between the two. It causes some issues with Windows Credential Manager and my push and pull requests.
